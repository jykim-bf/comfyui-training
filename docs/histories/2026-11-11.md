## ai-forge 에서 training 분리

- 사용자요청: `ai-forge/comfyui/training` 을 `~/dev/training` 으로 분리하고, 학습 스크립트와 ai-toolkit 도 같이 옮김. git 이력은 가져가지 않음.
- 처리내역요약: `configs/ inputs/ models/ outputs/` 를 그대로 옮기고, `vendor/ai-toolkit` 을 `ai-toolkit/` 로 옮겨 서브모듈로 다시 등록(881143c, 로컬 수정 없음). 학습·데이터셋 준비 스크립트 11개(`train_h3_*.sh`, `make_face_dataset.py`, `vlm_caption*.py`, `lora_captions.py`, `clean_captions.py`, `inject_distortion_tags.py`, `lora_inference.py`, `make_cloth_masks.py`)를 `scripts/` 로. 학습 스크립트는 `cd ~/dev/training` + `ai-toolkit/run.py configs/...` 로, `MODELS_PATH` 와 config 의 모델 경로는 `~/dev/comfyui/models` 로 바꿨다. VTON 데이터(`~/dev/ai-forge/data/vton/lora`)를 가리키는 옛 config 는 그대로 둠. `git init` 만 하고 커밋은 하지 않음. 상세는 `~/dev/comfyui/docs/histories/2026-11-11.md`.

## conda → uv 전환

- 사용자요청: uv 전환.
- 처리내역요약: conda `aitoolkit` 환경(Python 3.11.15)의 목록을 `requirements.lock.txt`(425개)로 고정해 `.venv`(uv)에 `--no-deps` 로 같은 버전을 설치. 인덱스 설정 `uv.toml`, 복구·목록 갱신 `scripts/venv_sync.sh`. 첫 설치 뒤 torch 2.13+cu130 이 `undefined symbol: ncclCommResume` 로 import 실패 — `nvidia-nccl-cu12`(2.27.5)와 `nvidia-nccl-cu13`(2.29.7)이 같은 `nvidia/nccl/lib/libnccl.so.2` 를 쓰는데 uv 에서는 cu12 가 이겼다(conda 는 cu13). 겹치는 경로를 conda 파일 해시와 비교해 nccl·nvshmem·cusparselt cu13, opencv(headless → opencv-python 4.10 순)를 다시 설치하고 `requirements.last.txt` 에 순서를 남겼다. 차이 0. 검증: torch CUDA·bf16 matmul, NCCL 2.29.7, ai-toolkit(`toolkit.job`)·diffusers·transformers import 정상. 학습 스크립트·config 주석은 `.venv/bin/python ai-toolkit/run.py` 로. VLM 캡션 단계(`vlm_caption*.py`)만 아직 conda `florence-cuda`. `torchcodec` 은 uv 에서 `0.9.1+cu130` 으로 깔렸지만 conda(0.9.1)와 마찬가지로 FFmpeg 라이브러리를 못 찾아 못 쓰는 상태 — 원래부터 깨진 것이라 그대로 둠. 옛 conda `aitoolkit` 환경은 지우지 않음.
